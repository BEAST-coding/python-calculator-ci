🧮 Python Calculator

This project demonstrates a simple Python calculator with automated testing using pytest and continuous integration via GitHub Actions.

🧪 Features

  • Basic arithmetic operations: add, subtract, multiply, divide
  • Unit tests with pytest
  • Automated CI workflow for test validation
